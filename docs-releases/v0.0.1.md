# Release 0.0.1

_Released 2026-05-08._ · [View on GitHub](https://github.com/closertools/execution-apis/releases/tag/v0.0.1)

[EMF Suppressor (v1.17.2)](https://github.com/ethereum/go-ethereum/releases/tag/v1.17.2) [Latest](https://github.com/ethereum/go-ethereum/releases/latest)
This is a maintenance release with several important bug fixes. Notably, a critical issue in debug_executionWitness could previously corrupt node data, users relying on this RPC endpoint are strongly advised to upgrade.

Geth now also supports syncing with chains where pre-Prague history has been pruned, and allows explicitly removing it via geth prune-history --history.chain postprague.

### Geth
Set default cache size to 4GB across all networks (https://github.com/ethereum/go-ethereum/pull/33836, https://github.com/ethereum/go-ethereum/pull/33975)
Added support for pruning chain history prior to the Prague fork (https://github.com/ethereum/go-ethereum/pull/33657, https://github.com/ethereum/go-ethereum/pull/34036)
Added fetchpayload command to build execution witnesses for specific blocks (https://github.com/ethereum/go-ethereum/pull/33919)
Optimized Era history import with batched insertion (https://github.com/ethereum/go-ethereum/pull/33894)
Added womir target for keeper (https://github.com/ethereum/go-ethereum/pull/34079)
Added support for iterating a single storage trie in geth snapshot traverse-state and geth snapshot traverse-rawstate (https://github.com/ethereum/go-ethereum/pull/34051)
### Core
Amsterdam fork updates:
EIP-8024: Switch to branchless normalization and extend EXCHANGE (https://github.com/ethereum/go-ethereum/pull/33869)
EIP-7778: Block gas accounting without refunds (https://github.com/ethereum/go-ethereum/pull/33593)
EIP-7954: Increase maximum contract size (https://github.com/ethereum/go-ethereum/pull/33832)
EIP-7708: ETH transfers now emit logs (https://github.com/ethereum/go-ethereum/pull/33645)
Reworked gas measurement order (prerequisite for EIP-7928) (https://github.com/ethereum/go-ethereum/pull/33648)
Improved payload building by prewarming trie nodes for state hash computation (https://github.com/ethereum/go-ethereum/pull/33945)
Various binary trie improvements (https://github.com/ethereum/go-ethereum/pull/33951, https://github.com/ethereum/go-ethereum/pull/33961, https://github.com/ethereum/go-ethereum/pull/33989, https://github.com/ethereum/go-ethereum/pull/34021, https://github.com/ethereum/go-ethereum/pull/34032, https://github.com/ethereum/go-ethereum/pull/34022, https://github.com/ethereum/go-ethereum/pull/34056)
Upgraded go-eth-kzg to v1.5.0, significantly reducing allocations in VerifyCellProofBatch (https://github.com/ethereum/go-ethereum/pull/33963)
Refactored state database in preparation for binary trie integration (https://github.com/ethereum/go-ethereum/pull/33816)
Enabled trie node history retention on existing nodes (https://github.com/ethereum/go-ethereum/pull/33934)
Optimized historical state indexer with batch processing (https://github.com/ethereum/go-ethereum/pull/33640)
Fixed potential deadlock in txlookup (https://github.com/ethereum/go-ethereum/pull/34039)
Added new RLP APIs (https://github.com/ethereum/go-ethereum/pull/34052, https://github.com/ethereum/go-ethereum/pull/34048)
Fix dir.Sync() failure in freezer on Windows (https://github.com/ethereum/go-ethereum/pull/34115)
### Networking
Avoid duplicate connections by skipping simultaneous inbound/outbound dials (https://github.com/ethereum/go-ethereum/pull/33198)
Fixed session key mismatch by using consistent remote address handling in discv5 tests (https://github.com/ethereum/go-ethereum/pull/34031)
Added DNS hostname resolution for bootstrap nodes (https://github.com/ethereum/go-ethereum/pull/34101)
